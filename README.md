# thinking-in-elm

A redesigned version of Elm’s documentation, aiming to simplify learning the language and functional programming concepts in Elm through a clearer, more intuitive representation.

## Setup

1. Run `npm run dev` to compile Elm on the fly
2. Open `index.html` in the browser by double-clicking it in the file browser (`file://)` or run `http-server .` (installed globally) from the root of the project

_NOTE: `http-server` is installed globally via [Volta](https://volta.sh/)_
